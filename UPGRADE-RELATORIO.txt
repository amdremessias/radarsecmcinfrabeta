# TASK: Implementação de Relatório Detalhado de Segurança e Exportação para PDF

## Objetivo
Implementar um gerador de relatórios técnicos e executivos em PDF no backend/frontend do **MCinfraTI Radar Security**. O relatório deve elevar o nível visual da tela atual, incluindo indicadores de risco, resumos executivos, matriz de severidade e ações corretivas detalhadas.

---

## 1. Estrutura e Seções do Relatório (Layout / UX)

O relatório em PDF deve conter as seguintes seções estruturadas:

1. **Capa Executiva:**
   - Logotipo `MCinfraTI Radar Security`.
   - Alvo analisado (URL/Domínio ou Repositório).
   - Data/Hora de execução, Duração e ID do Scan.
   - **Score de Segurança Big Number** (Ex: `27/100`) e a **Nota de Segurança** (Ex: `Grade F` em destaque vermelho).

2. **Sumário Executivo (Dashboard Metric Cards):**
   - Cards com contadores por categoria:
     - **Cabeçalhos de Segurança:** `0/6` (Ex: Falhas de HSTS, CSP, X-Frame).
     - **Cookies:** Proteções `HttpOnly`, `Secure`, `SameSite`.
     - **TLS / SSL:** Validade de certificados, ciphers e protocolos.
     - **DNS & Subdomínios:** Registros SPF/DMARC e enumeração.
     - **Tecnologias & Vulnerabilidades:** Softwares identificados e CVEs detectados.
   - **Matriz de Vulnerabilidades:** Gráfico/Tabela com contagem por severidade (`CRÍTICO`, `ALTO`, `MÉDIO`, `BAIXO`, `INFO`).

3. **Detalhamento Técnico por Categoria:**
   - Tabelas estilizadas contendo:
     - **Item / Header / Recurso**
     - **Status:** Badge colorido (Passou = Verde, Falhou = Vermelho, Alerta = Amarelo).
     - **Impacto / Descrição:** Explicação clara do risco.
     - **Recomendação de Correção:** Instruções técnicas e trechos de código/configuração recomendados.

4. **Rodapé de Compliance e Assinatura:**
   - Declaração de confidencialidade e dados de contato da **MCinfraTI**.

---

4. Serviço de Geração do PDF em Node.js (src/services/pdf-report.service.ts)
TypeScript
import puppeteer from 'puppeteer';
import handlebars from 'handlebars';
import * as fs from 'node:fs/promises';
import * as path from 'node:path';

export interface ReportData {
  targetUrl: string;
  score: number;
  grade: string;
  executionDate: string;
  duration: string;
  headersPassed: number;
  cookiesCount: number;
  techCount: number;
  subdomainsCount: number;
  headersList: Array<{
    name: string;
    passed: boolean;
    recommendation: string;
  }>;
}

export class PdfReportService {
  public static async generateReport(data: ReportData): Promise<Buffer> {
    // 1. Carrega e compila o template Handlebars
    const templatePath = path.join(__dirname, '../templates/report.hbs');
    const htmlTemplate = await fs.readFile(templatePath, 'utf-8');
    const compiledTemplate = handlebars.compile(htmlTemplate);
    const htmlContent = compiledTemplate(data);

    // 2. Inicializa o Puppeteer para renderização
    const browser = await puppeteer.launch({
      headless: true,
      args: ['--no-sandbox', '--disable-setuid-sandbox']
    });

    const page = await browser.newPage();

    // Define o conteúdo da página e aguarda o carregamento das fontes/estilos
    await page.setContent(htmlContent, { waitUntil: 'networkidle0' });

    // 3. Exporta para PDF em formato A4
    const pdfBuffer = await page.pdf({
      format: 'A4',
      printBackground: true,
      margin: {
        top: '20px',
        right: '20px',
        bottom: '20px',
        left: '20px'
      }
    });

    await browser.close();
    return Buffer.from(pdfBuffer);
  }
}
