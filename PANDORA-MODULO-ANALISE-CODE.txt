TASK: Módulo "Análise Profunda" (SAST & Code Audit UI) — MCinfraTI Radar Security
🎯 Objetivo
Criar uma nova aba na área administrativa chamada "Análise Profunda". Ela permitirá ao usuário submeter o código-fonte de um projeto — seja colando a URL de um repositório Git ou fazendo upload de um arquivo compactado (ZIP) — para executar a auditoria estática baseada nos 5 pilares de segurança (Banco Sem Tranca, Permissões no Navegador, IDOR, Chaves Expostas e Inputs sem Tratamento).

🏗️ 1. Arquitetura da Interface (UI/UX)
A tela deve ser dividida em duas etapas principais:

Configuração da Análise (Formulário de Entrada)

Dashboard de Resultados (Visualização e Ações)

Componentes Principais da UI
Seletor de Origem do Código (Tabs/Cards):

Aba Repositório Git: Campo de input para URL ([https://github.com/usuario/repositorio](https://github.com/usuario/repositorio)), seleção de branch (default: main) e campo para Personal Access Token (PAT) caso o repositório seja privado.

Aba Upload de Arquivo: Zona de Drag & Drop aceitando arquivos .zip ou .tar.gz (limite máximo sugerido: 50MB).

Painel de Status da Execução (Progress Bar):

Métrica visual em tempo real mostrando as etapas: Upload / Git Clone → Detecção de Stack → Varredura SAST → Geração do Relatório.

Área de Resultados (Dashboard Interativo):

Resumo da Stack: Cards com badges mostrando linguagem, framework, ORM e arquivos de deploy identificados.

Filtros Rápidos: Botões para filtrar por severidade (CRÍTICA, ALTA, MÉDIA, BAIXA, PONTOS FORTES) e por pilar de falha.

Lista de Vulnerabilidades (Accordion List): Cada item expansível mostra:

Badge de Severidade e Caminho do Arquivo com Número da Linha (src/api/auth.ts:45).

Blockquote com o trecho de código vulnerável com destaque de sintaxe (Syntax Highlighting).

Explicação clara de por que o trecho é explorável e a sugestão de correção.

Botão "Copiar Issue GitHub" para área de transferência.

Barra de Ações da Header:

Botão "Exportar PDF Completo" (chama a rota de PDF com o template compilado).

🛠️ 2. Especificação do Backend e API
Endpoint de Submissão para Análise
POST /api/admin/deep-analysis/scan

Payload (para repositório Git):
JSON
{
  "sourceType": "GIT",
  "repositoryUrl": "https://github.com/empresa/projeto-backend.git",
  "branch": "main",
  "apiToken": "ghp_xxxxxxxxxxxx", // Opcional (repositórios privados)
  "projectName": "Projeto Backend Produção"
}
Payload (para upload de ZIP - multipart/form-data):
file: arquivo .zip

projectName: string

sourceType: "ZIP"
